# ADR 0008 — Beauty skin mask

**Статус:** принято, 2026-10-19.

## Контекст

Украшательства были почти незаметны: альфа смешивания 0.275, а маска
строилась как эллипс лица минус небольшие круги глаз/рта. Попытка
заменить её на YCrCb-порог кожи на этой камере провалилась:

| Область | Cr | Cb | Попадает в «кожу» 128..180 / 70..135 |
|---|---|---|---|
| лоб | 121.9 | 122.9 | нет (Cr ниже порога) |
| правая щека | 119.5 | 128.9 | нет |
| левая щека | 130.0 | 124.4 | да |
| борода | 129.1 | 126.3 | да (нежелательно) |
| стена | 122.2 | 127.2 | почти как кожа |

Итог: лоб не сглаживался, борода/очки попадали в эффект, а видимая
разница была на уровне шума. Цвет на этой камере (простой ISP + тёплый
свет) не разделяет кожу и фон.

## Решение

Маска кожи строится геометрией лица и яркостью, без цветового порога:

1. Эллипс внутри bbox лица: полуоси `0.58·faceW`, `0.62·faceH`.
2. Порог яркости `Y > 80` — убирает тёмные волосы, бороду, оправу очков.
3. Срез выше линии роста волос: `y >= faceTop + 0.02·faceH`.
4. Боковой срез ниже линии глаз: `|x − faceCenter| <= 0.40·faceW` —
   убирает бакенбарды/бороду по краям.
5. Нижняя граница по центру рта: `y <= mouthY` — убирает бороду/подбородок.
6. Явные исключения: глаза (круги `0.09·faceW` по 35 точкам) и губы
   (эллипс `0.22·faceW × 0.10·faceH`).
7. Сглаживание: bilateral `d=9`, `sigmaColor=30+60·strength`, плюс glow
   (Gaussian, вес 0.4) — частота разделяется, текстура уходит, край лица
   сохраняется.
8. Тон: `gain=1+0.08·strength`, `lift=10·strength` только по маске кожи.
9. Смешивание: `alpha=strength` (0.7 по умолчанию), значение 1.0
   ограничено 0.9.
10. UI: подменю «Сила украшательств» — 0.4 / 0.7 / 1.0; выбор силы сразу
    включает `beauty` (или `blur-beauty`, если размытие уже включено).

Превью вызывают процессор с `temporal=false`, поэтому не портят
live-историю; видео — с `temporal=true` (EMA из ADR 0006).

## Замеры (контролируемый CLI, один и тот же кадр)

| Область | off | beauty 0.7 | Δ |
|---|---|---|---|
| лоб | 144.8 | 151.8 | +7.0 |
| левая щека | 105.8 | 107.7 | +1.9 |
| правая щека | 178.1 | 180.4 | +2.3 |
| борода | 70.2 | 70.2 | 0.0 |
| очки | 136.1 | 142.8 | +6.7 (стёкла/кожа за ними) |

CLI: beauty 29 мс, blur-beauty 43 мс; живой vcam — 30.0–30.2 fps.

## Последствия

- Эффект виден на лбу/щеках, борода и оправа не размываются.
- У чистобритого пользователя нижняя часть подбородка не обрабатывается
  (нижняя граница по рту) — сознательный компромисс ради бороды.
- В глубокой тени (`Y < 80`) кожа не сглаживается.
- Стёкла очков могут слегка светлеть; оправа тёмная и не сглаживается.
- Нет семантической модели лица; это эвристика под текущую камеру.

## Альтернативы

- **YCrCb-порог**: провалился (таблица выше).
- **Face parsing ONNX** (BiSeNet, 19 классов): точнее (кожа/волосы/очки/
  губы), но +модель, +память и +время; кандидат на следующую версию.
- **MediaPipe multiclass selfie** (6 классов): класс face-skin — это blob
  всего лица, включая бороду/очки; 23.6 мс на NPU; не даёт skin-only.
- **Полный эллипс без исключений**: сглаживает бороду/очки, выглядит
  неестественно.
